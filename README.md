# 模拟器管理工具 v4.1

雷电模拟器实例管理 + 定时关闭 + 自动关机/重启

## 功能

### 定时关闭实例
- ⏰ **定点 / 倒计时两种模式** — 支持每天定点关闭或设定倒计时
- 🔄 **自动重置** — 定点任务关闭后自动重置到第二天同一时间
- 🚀 **一键启动/停止** — 批量启动或停止所有定时任务
- 🔗 **自动关机** — 关闭模拟器后自动关机或重启（由全局"关闭后操作"控制）

### 实例管理
- 🔍 **自动路径探测** — 支持运行中进程、注册表、pathconfig.ini、常见路径扫描
- 📋 **实例列表** — 自动扫描所有实例，显示 CPU/内存/Root 设置与运行状态
- ✏ **设置编辑** — 修改分辨率、CPU、内存、Root、帧率、设备名等
- 💾 **配置快照** — 一键保存所有实例设置，随时恢复
- 🚀 **间隔启动** — 勾选要启动的实例，设置间隔秒数批量启动
- 🔁 **开机自启实例** — 勾选后，软件启动时自动恢复配置并启动实例

### 关闭操作
- 🔒 **一键关闭所有模拟器** — 优雅关闭 → 超时强制，可联动关机/重启
- 📂 **配置自动备份** — 每次关闭前自动备份 LDPlayer 配置文件到 `备份/` 目录
- 🧹 **智能清理** — 备份目录最多保留 20 份，超出的旧备份自动删除

### 关机/重启
- ✅ **关闭后关机** — 关闭模拟器后自动关机电脑
- ✅ **关闭后重启** — 关闭模拟器后自动重启电脑
- 🛡 **多级强制关机** — shutdown.exe → ExitWindowsEx → InitiateShutdown → wmic
- 🔄 **同时作用于**：「关闭所有模拟器」按钮 **和** 定时关闭任务

## 路径自动探测策略

| 优先级 | 策略 | 说明 |
|--------|------|------|
| 1 | 运行中进程 | 从 wmic 获取 dnplayer.exe / ldplayer.exe 路径 |
| 2 | pathconfig.ini | 多开器配置文件中记录了 LDPlayer 路径 |
| 3 | Windows 注册表 | HKLM/HKCU 下 LDPlayer 相关键值 |
| 4 | 常见路径扫描 | C/D/E 盘的 LDPlayer9/LDPlayer8/LDPlayer |

探测结果保存到 `instance_config.json`，下次启动直接使用。

## 使用方法

### 图形界面模式

1. 双击运行 `模拟器管理工具.exe`
2. 首次启动自动探测 LDPlayer 路径
3. **定时关闭区**：
   - 点击「+」添加定时关闭任务（定点时间或倒计时）
   - 勾选启用，点击 ▶ 启动定时任务
   - 支持定点模式自动重置（每天同一时间触发）
4. **实例管理区**：
   - 勾选实例 → 点击「编辑设置」修改参数
   - 点击「保存快照」备份当前所有设置
   - 点击「恢复快照」从之前的快照恢复
   - 勾选实例 → 设置间隔秒数 → 点击「启动」批量启动
5. **操作区**：
   - 点击「关闭所有模拟器」关闭所有运行中的模拟器
   - 勾选「关机」或「重启」控制关闭后的操作
   - 关闭后操作同时影响「关闭所有模拟器」按钮和定时关闭任务
6. **底部栏**：
   - 「开机自启工具」— 软件随系统自动启动

### 配置文件结构

```
工具目录/
├── instance_config.json      # 工具配置（路径、启动计划）
├── 快照/                     # 配置快照
│   └── 2026-06-13_10-30/
│       ├── leidian0.config   # 实例设置
│       ├── leidians.config   # 全局设置
│       └── snapshot_meta.json
└── tasks_config.json         # 定时任务配置
```

## 打包部署

```bash
# 使用 uv 安装 PyInstaller
uv pip install pyinstaller

# 打包（需要包含 ld_instance_manager.py）
pyinstaller --onefile --noconsole --name "模拟器管理工具" \
  --add-data "ld_instance_manager.py;." \
  模拟器定时关闭工具.py

# 输出在 dist/ 目录，成品可放到任意目录运行
```

部署到其他电脑时，工具会自动搜索 LDPlayer 安装路径。

## 技术栈

- **Python 3.11+** — tkinter GUI
- **PyInstaller** — 打包为独立 exe
- **ctypes** — Windows API 调用
- **dnconsole.exe / ldconsole.exe** — 雷电模拟器命令行控制
- **wmic / tasklist** — 进程扫描
