# 模拟器管理工具

雷电模拟器实例管理 + 定时关闭 + 自动关机/重启

## 功能

### 定时关闭实例
- **定点 / 倒计时两种模式** — 支持每天定点关闭或设定倒计时
- **自动重置** — 定点任务关闭后自动重置到第二天同一时间
- **一键启动/停止** — 批量启动或停止所有定时任务
- **自动关机** — 关闭模拟器后自动关机或重启

### 实例管理
- **自动路径探测** — 支持运行中进程、注册表、常见路径扫描
- **实例列表** — 自动扫描所有实例，显示 CPU/内存/Root 设置与运行状态
- **设置编辑** — 修改分辨率、CPU、内存、Root、帧率、设备名等
- **配置快照** — 一键保存所有实例设置，随时恢复
- **间隔启动** — 勾选要启动的实例，设置间隔秒数批量启动
- **开机自启实例** — 软件启动时自动恢复配置并启动实例

### 关闭操作
- **一键关闭所有模拟器** — 优雅关闭 → 超时强制，可联动关机/重启
- **配置自动备份** — 每次关闭前自动备份 LDPlayer 配置文件
- **备份上限** — 备份目录最多保留 20 份，超出自动清理

### 关机/重启
- **关闭后关机** — 关闭模拟器后自动关机电脑
- **关闭后重启** — 关闭模拟器后自动重启电脑
- **多级强制关机** — shutdown.exe → ExitWindowsEx → InitiateShutdown → wmic

## 使用方法

1. 下载 `成品/模拟器管理工具.exe`
2. 首次启动自动探测 LDPlayer 路径
3. 根据需要设置定时关闭任务或管理实例

## 从源码打包

```bash
uv pip install pyinstaller
pyinstaller --onefile --noconsole --name "模拟器管理工具" 模拟器定时关闭工具.py
```

## 技术栈

- Python 3.11+ — tkinter GUI
- PyInstaller — 打包为独立 exe
- ctypes — Windows API 调用
- dnconsole.exe / ldconsole.exe — 雷电模拟器命令行控制
