# Auto Shutdown Tool Maintenance

本项目的自动关闭、关机联动与定时任务维护指南，改写自 Hermes Desktop 的相关经验。

## 任务状态

- 修改 `running`、`enabled`、目标时间或实例选择后立即保存。
- 调用可能长时间运行的优雅关闭流程前，先保存任务状态；完成回调中再保存一次。
- 任务线程异常时记录日志并恢复 `running=False`，避免任务永久显示执行中。
- 固定时间任务完成后应正确滚动到下一天；倒计时任务不能意外套用固定时间逻辑。

## 关机联动

- 关机/重启必须由明确的用户操作或已启用的任务选项触发。
- 测试扫描、UI 冒烟测试和构建验证不得执行真实电源操作。
- 任何电源操作前必须确认模拟器关闭流程已完成，并在日志中记录结果。
- 需要管理员权限的失败应显示具体提示，不要吞掉错误。

## 验证

优先验证任务创建、启停、删除、配置重载和模拟器关闭后的联动状态。不要为了测试使用真实关机命令。
